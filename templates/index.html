Ship your workspace

Deployments

Deployment guidance for GitHub-based development and a Python-capable host.
GitHub stores your code; GitHub Pages does not run Flask/Python. Deploy this project to a Python-capable host, or use a server/worker you control.
Recommended deployment path
1
Push the project to a GitHub repository
Keep secrets out of source control; add .env to .gitignore.
2
Create a Python web service
Use the included requirements.txt and Procfile/start command: gunicorn app:app
3
Set environment secrets
Set LLM_API_KEY and optionally LLM_BASE_URL in your host's secret settings.
4
Check health endpoint
Open /health after deployment; persistent storage depends on host configuration.
Credentials

API Keys

Connect an API key from an LLM provider that supports the OpenAI-compatible chat completions format.
Security: for a public deployment, prefer the host's secret/environment-variable manager. A key saved through this demo is stored in a local JSON settings file and is not suitable for a multi-user production service.
Provider credentials
Key is never shown again in full. Existing environment key takes precedence.

LLM Gateway

How tiers work

Fast / Pro / Max are labels in this app, not universal provider model names. Set each field to a model ID available to your own API account. Usage may be billed by your provider.

Maintenance & environment

Updates & Runtime

Inspect the Python environment and installed packages. Application code upgrades should be reviewed and deployed deliberately.
This is a safe runtime inspector, not a self-modifying system. It does not silently rewrite source code, install arbitrary packages, or consume all repository storage. Use reviewed Git commits and deployments to update the app.
